# Wu Nano Lab Homepage

Repo holds the Wu Nano Lab website (Jekyll).

- First time: `bundle install`, `cd react && npm install`.
- In VS Code
    - Terminal → Run Build Task 
    - Run Task → "npm: **watch** - react"
- Edit site content in Jekyll ([/_pages](/_pages), [/_posts](/_posts)) or edit [react/src](react/src) for the pages implemented in React.
- The following pages are implemented in React (see [react/pages/](react/pages/)): `biomed.html`, `equipment.html`, `team.html`.
